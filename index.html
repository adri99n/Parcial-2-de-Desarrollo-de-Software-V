¿Qué es el Vibe Coding?

El Vibe Coding es una manera de desarrollar programas con ayuda de la inteligencia artificial. En lugar de escribir cada línea de código, una persona explica con palabras lo que necesita y un modelo de inteligencia artificial genera el código correspondiente.

Una característica de esta práctica es que el usuario puede centrarse en el resultado sin revisar detalladamente todo el código generado. Por ejemplo, puede pedir una página web, probarla y solicitar cambios hasta que funcione como espera.

Imagen: ANIRUDHpatki / Wikimedia Commons

Origen del término

La expresión Vibe Coding fue popularizada por Andrej Karpathy en febrero de 2025. Su idea describe una forma de programar en la que se dan instrucciones a una IA y se aceptan sus resultados sin concentrarse necesariamente en los detalles del código.

¿Cómo funciona?

Primero se describe lo que se quiere hacer. Después, la herramienta genera código. El usuario lo ejecuta, comprueba si funciona y puede pedir cambios. Este proceso se repite hasta obtener el resultado deseado. Aunque permite avanzar rápido, el código siempre puede contener errores.

Para conocer más sobre el tema puedes consultar el artículo de Wikipedia sobre Vibe Coding.
